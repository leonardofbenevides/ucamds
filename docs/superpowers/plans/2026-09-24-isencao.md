# Isenção de disciplinas — plano de execução

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O protótipo `isencao-v2-prototipo.html` vira o projeto `isencao` em `spec/templates.json`, com seis telas de referência que se comportam como o sistema, publicadas no site em Telas e como telas autônomas em `/t/isencao-*.html`.

**Architecture:** As telas são dados (marcação HTML no campo `preview` de cada template) gerados por um script de scratchpad que lê e grava `spec/templates.json` no mesmo instante; o comportamento vem dos scripts compartilhados de `tools/lib/shell.mjs`, que ganham os tratadores das ações novas; a folha ganha uma classe (contador do textarea) e o contrato do textarea a declara. Nada de CSS por tela, nada de toast.

**Tech Stack:** JSON da spec, HTML com classes `ucam-*` do @ucam/css, JavaScript sem dependência em `tools/lib/shell.mjs`, Node 24, pnpm, CDP contra Chrome headless para as sondas.

**Spec:** `docs/superpowers/specs/2026-09-24-isencao-design.md`

## Global Constraints

- Toda tela implementa um padrão de `spec/patterns/patterns.json` e usa só componentes com contrato (`_meta` de templates.json).
- Todo `href` de preview segue `#/templates/<projeto>/<tela>` e aponta tela declarada (validador 4d).
- Todo botão declara `data-fluxo`: `a` é link para tela, `b` não tem tela e recebe `data-sem-tela`, `c` age na própria tela por `data-acao` (ADR-033).
- Efeito de ação chega por um dos cinco canais da sonda de feedback: `[data-anuncio]`, `role=status`, foco, nome acessível, estado ARIA. Toast está fora do catálogo.
- Escolhido: realce de superfície + peso 560; nenhuma tinta cheia de marca em aba, chip ou período (ADR-046).
- Nenhuma caixa alta forçada (ADR-003). Identificadores em `.ucam-id` (ADR-047), nunca em título.
- Tabela de uma linha por célula em `ucam-table--compact`; célula de pessoa `.td--pessoa` (ADR-046).
- Cores só por token semântico; nenhum hex e nenhum `style` além dos que as telas existentes já usam (`--ucam-split-aside`, `margin-block-end`, `padding:0;overflow:hidden`).
- Sessões paralelas editam `spec/templates.json` e `tools/lib/shell.mjs`: o gerador lê e grava no mesmo instante e confere com `grep` depois.
- Números que fecham (spec): 8 em análise = 3 + 3 + 2; 5 concluídas; Direito 5, Administração 3; João Cutrim 9 disciplinas = 4 + 3 + 2, sugestões 4/2/3, decisões 4/2/3; Pedro Alves 6 de 9.
