# UCAMDS Sites, fatia 3a-1: a lib `@ucam/site-ui`, o portão de paridade e cinco peças

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nascer a lib Angular dos sites com button, tag, icon-chip, avatar e section-heading, e com o portão que prova que cada peça Angular produz o mesmo DOM da demo do catálogo.

**Architecture:** A lib não tem estilo: cada peça é uma diretiva ou um componente de seletor de ATRIBUTO sobre o elemento nativo do contrato, e só aplica as classes de `@ucam/site-css`. As demos Angular vivem em `sites/spec/demos.json` (campo `angular`), e um gerador as transforma em componentes que o teste de unidade e o site de docs usam, então o código documentado é o código testado.

**Tech Stack:** Angular 22, ng-packagr, `@angular/build:unit-test` (vitest + jsdom), Node 24 ESM, pnpm 11. Mesmo arranjo de `ui/`.

**Spec:** `docs/superpowers/specs/2026-10-10-sites-ui-design.md`. Formato compacto, como os planos 2b e 2c: o plano fixa decisões, nomes e os trechos que não podem variar; o que é mecânico segue o padrão dito.

**Decisões:**
- O campo novo da demo é `angular`, ao lado de `codigo`. `codigo` continua sendo o HTML, porque o validador cobra as classes nele. (Refina a spec, que punha o Angular em `codigo`.)
- Cada componente gerado é `@Component({ imports: [UCAM_SITE], template: <a string de `angular`, em literal> })`. `UCAM_SITE` é o vetor com todas as peças, exportado por `public-api.ts`; nasce na Tarefa 3 e o gerador só emite componentes de peças que têm `angular`, então nesta tarefa o arquivo gerado sai com `DEMOS = {}`.
- O template vai como literal de crase; o gerador escapa crase, `${` e barra invertida, e REPROVA demo cujo `angular` contenha `</script`.
- `normalizar` percorre a árvore e escreve, por elemento, uma linha `<tag classes-em-ordem-alfabética atributos>` indentada pela profundidade, e o texto com espaços colapsados. Atributos que contam: `role`, todo `aria-*`, `href`, `type`, `disabled`, `alt`, `src`, `for`, `id`, `name`, `open`, `tabindex`. Ignora comentários, atributos `_ng*` e `ng-*`, nós de texto vazios, e todo atributo fora da lista (é onde ficam os seletores de diretiva e as entradas estáticas, como `variant="primary"`).
- `<svg class="ic"><use href>`: conta a classe, o `aria-hidden` e o `href` do `use`.

```ts
import { Component } from '@angular/core';
import { TestBed } from '@angular/core/testing';
import { renderApplication } from '@angular/platform-server';
import { bootstrapApplication } from '@angular/platform-browser';
import { DEMOS } from '../../testing/demos.gerado';
import { contratoDe } from '../../testing/contrato';
import { mesmaArvore } from '../../testing/paridade';
import { UcamSiteButton } from './button';

const { props, raiz } = contratoDe('button');

@Component({ imports: [UcamSiteButton], template: `<a ucamSiteButton class="minha" [variant]="variant" [size]="size" [inverse]="inverse">x</a>` })
class Hospede { variant: string = 'primary'; size: string = 'md'; inverse = false; }

const classesCom = (mudanca: Partial<Hospede>) => {
  const f = TestBed.createComponent(Hospede);
  Object.assign(f.componentInstance, mudanca);
  f.detectChanges();
  return new Set((f.nativeElement.querySelector('a') as HTMLElement).className.split(' ').filter(Boolean));
};

describe('[ucamSiteButton]', () => {
  it('cada valor do contrato aplica a classe que o contrato diz, e só ela', () => {
    for (const p of props.filter((p) => p.valores)) {
      for (const [valor, v] of Object.entries(p.valores!)) {
        const entrada = p.tipo === 'boolean' ? valor === 'true' : valor;
        const classes = classesCom({ [p.nome]: entrada } as never);
        expect(classes.has(raiz)).toBe(true);
        if (v.classe) expect(classes.has(v.classe.replace(/^\./, ''))).toBe(true);
      }
    }
  });
  it('valor fora do contrato cai no padrão e não inventa classe', () => {
    const classes = classesCom({ variant: 'outline' });
    expect([...classes].some((c) => c.includes('outline'))).toBe(false);
    expect(classes.has('ucam-site-btn--primary')).toBe(true);
  });
  it('a classe do consumidor sobrevive', () => {
    expect(classesCom({ variant: 'ghost' }).has('minha')).toBe(true);
  });
  it('cada demo Angular produz a árvore da demo em HTML', () => {
    for (const d of DEMOS['button']) {
      const f = TestBed.createComponent(d.componente);
      f.detectChanges();
      const r = mesmaArvore(d.html, f.nativeElement);
      expect(r.igual, `${d.titulo}: ${r.diferenca}`).toBe(true);
    }
  });
  it('no servidor o HTML já sai com as classes', async () => {
    @Component({ selector: 'app-raiz', imports: [UcamSiteButton], template: `<a ucamSiteButton variant="secondary" href="/x">x</a>` })
    class Raiz {}
    const html = await renderApplication(() => bootstrapApplication(Raiz), { document: '<app-raiz></app-raiz>' });
    expect(html).toContain('class="ucam-site-btn ucam-site-btn--secondary"');
  });
});
```
